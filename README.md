# 🎯 Scientific Habit Tracker

Build better habits with **proven behavioral psychology**. Track daily habits, maintain streaks, earn achievements, and see your growth through beautiful analytics.

## ✨ Features

- **📅 Daily Habit Tracking** — Check off habits with one tap, grouped by time of day
- **🔥 Streak System** — Don't break the chain! Visual streak counters with emoji levels
- **📊 GitHub-Style Heatmap** — See your consistency at a glance with a contribution grid
- **💬 150+ Motivational Quotes** — Context-aware quotes that change based on your progress
- **🏆 Achievement Badges** — Unlock 20+ badges as you build consistency
- **📈 Analytics Dashboard** — Weekly trends, success rates, and best-day insights
- **🧠 Science-Backed** — Built on Habit Loop, Implementation Intentions, and Streak Psychology
- **📱 PWA Ready** — Install on your phone, works offline
- **🔒 Private** — All data stays in your browser (localStorage), no server needed

## 🧪 Scientific Foundations

| Framework | Source | Application |
|-----------|--------|-------------|
| Habit Loop | Duhigg / MIT Research | Cue → Routine → Reward prompts |
| Implementation Intentions | Gollwitzer (1999) | "I will [behavior] at [time] in [location]" |
| Don't Break the Chain | Seinfeld Method | Visual streak tracking |
| Temptation Bundling | Milkman (Wharton) | Pair hard habits with enjoyable activities |
| 66-Day Rule | Lally, UCL (2009) | Progress toward automaticity |

## 🚀 Quick Start

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/habit-tracker.git
cd habit-tracker

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🛠 Tech Stack

- **React 18** + **Vite** — Fast modern build
- **Tailwind CSS v4** — Utility-first styling
- **Chart.js** — Analytics visualizations
- **canvas-confetti** — Celebration effects
- **localStorage** — Zero-cost data persistence
